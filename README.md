## 🛠️ Despliegue

### GitHub Pages (Recomendado)

1. Sube este repositorio a GitHub
2. Ve a Settings > Pages
3. Selecciona "Deploy from a branch"
4. Elige la rama `main` y carpeta `/root`
5. ¡Listo! Tu sitio estará en `https://username.github.io/repository/`

### Otros Servicios

- Cloudflare Pages
- Cualquier hosting estático

## 📝 Personalización

- Edita `index.html` para modificar el contenido
- Ajusta los estilos en `styles/main.css`
- Modifica las variables en `styles/tokens.css`
- Actualiza los metadatos en `data/site.json`
